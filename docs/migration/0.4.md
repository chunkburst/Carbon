# Legacy migration reader

This page documents the only supported historical-input exception in Carbon. It is not an
alternate current workflow and it does not change Carbon's canonical names, `.carbon/` storage,
`carbon` binary, or MCP v2 contract.

## What the reader may consume

The explicit migration reader may inspect only a historical source containing:

```text
<legacy-root>/.cairn-cluster.json
<legacy-project>/.cairn/
```

Those paths are a **read-only import source**. They are never normal Carbon storage locations, and
they must not be supplied to regular Carbon Home/project operations.

## Safe migration flow

1. Choose or create the target Carbon Home.
2. Generate a dry-run plan with `carbon home import --home <home> --legacy-cluster <legacy-root>`.
3. Review the plan, source fingerprints, ownership mapping, collision/reference rewrites, and
   `reviewDigest`.
4. Apply only a freshly generated reviewed plan with `--apply --expected-digest <reviewDigest>`.
5. Verify the target Home and its local snapshot after publication.

The reader re-plans under the Home lock before apply. It never trusts a serialized plan as a write
recipe. Carbon stages the target privately, publishes only validated copies, and retains a receipt.

## What stays unchanged

The historical source is not renamed, moved, deleted, or rewritten. Carbon does not mutate its
task files, sessions, run evidence, registry, source repositories, or configuration. A migration
creates Carbon-owned target data under the selected Home:

```text
<home>/.carbon/
  home.json
  clusters/<cluster-id>/.carbon/
  backups/
```

The imported shared pool has stable project ownership and any required collision/reference rewrites
only in the Carbon target. A user may later create standalone projects normally; the migration
reader does not force new work into a cluster.

## Reader exceptions

| Historical input | Allowed use | Mutation | Current replacement |
| --- | --- | --- | --- |
| `.cairn-cluster.json` | Reviewable registry import source | Never modified | Carbon Home manifest at `.carbon/home.json` |
| `.cairn/` | Read-only historical task/session source | Never modified | Carbon project or optional cluster store under `.carbon/` |

No historical identifier is accepted as a current CLI, MCP configuration, deep-link, environment,
or HTTP actor-header name. See the [canonical-name audit](/migration/canonical-name-audit) for the
complete exception inventory.
